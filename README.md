# The Rewire Lab

Company site for The Rewire Lab, the team behind [PredictiveMind](https://predictivemind.io/).

## Pages

- `/`: short introduction
- `/privacy`: privacy policy
- `/terms`: terms of service

## Develop

```bash
cp .env.example .env.local
yarn install
yarn dev
```

Open [http://localhost:3000](http://localhost:3000).
